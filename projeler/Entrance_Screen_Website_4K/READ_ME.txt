ENTRANCE SCREEN / 4K (DEMO)

Demo version: the original films and logos were removed (copyright). The two videos in the media folder are 4K placeholder films.

OFFLINE USE
1. Extract the entire ZIP to the entrance-screen computer.
2. Keep index.html, screen.css, player.js and the media folder together.
3. Open index.html in Chrome or Edge.
4. Playback starts automatically, muted. If the browser asks, click Start playback.
5. Click Enter full screen, or press F. Controls disappear automatically.
6. Set the connected display output to 3840 × 2160 for native 4K.

PLAYLIST
1. Timeline — 12 seconds, 3840 × 2160, 30 fps (placeholder).
2. Session departures — 12 seconds, 3840 × 2160, 30 fps (placeholder).
The two videos alternate continuously. Both are silent. The files are the original 4K masters, not the 1080p review copies.
The timeline includes the revised row-opening transitions.
The sessions video is the existing recorded arrivals/departures programme loop, not the clock-controlled live session board.

CONTROLS
Move the pointer to show controls.
F: Full screen. Space: Pause / Play. N: Next film.
1: Timeline. 2: Sessions. O: Show / hide controls.
Info: Check the video dimensions or select a film.

VENUE
Disable the operating system's sleep/screensaver for the show. The player also requests a screen wake lock where the browser supports it.
Use the display's native resolution and a suitable 4K HDMI/DisplayPort connection. A 1080p computer output cannot display native 4K, even though the video files are 4K.
No installation, online assets or internet connection is required for the offline copy.
No messages or registrations are sent by this page.

HOSTING
The same files can be uploaded together to any static web host. Serve .mp4 as video/mp4. Byte-range requests are recommended.
