# 3B Scroll · Demo

Scroll ile hareket eden 3B ürün sunumu (WEBGi + GSAP ScrollTrigger).

Telif nedeniyle orijinal 3B model ve görseller kaldırıldı; `assets/scene.glb` kodla üretilmiş soyut bir yer tutucu modeldir. Gerçek ürün modeli aynı adla değiştirilerek kullanılabilir.

Açık kaynak bir three.js / WEBGi scroll örneğinden uyarlanmıştır.
